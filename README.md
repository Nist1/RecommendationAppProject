# RecommendationApp

Рекомендательная система на основе анализа текстовых данных. Поддерживает два алгоритма рекомендаций, авторизацию пользователей и персональную историю поиска.

## Стек технологий

**Backend:** Django 6.0, SQLite  
**Frontend:** React, Axios  
**ML:** scikit-learn (TF-IDF), sentence-transformers (SBERT), pymorphy3

---

## Функциональность

### Два режима рекомендаций
Переключатель на главной странице позволяет выбрать алгоритм:

- **TF-IDF** — классическая векторизация с косинусным сходством. Быстрый, работает офлайн, не требует дополнительных ресурсов.
- **Sentence Transformers** — семантические эмбеддинги на базе модели `paraphrase-multilingual-mpnet-base-v2`. Понимает смысл запроса, работает с русским языком, даёт более релевантные результаты. Модель загружается локально (~400MB), интернет нужен только при первом скачивании.

### Рекомендации
- **Основной поиск** — топ-5 релевантных документов по запросу
- **Похожие статьи** — открываются по клику на карточку
- **Вам также может быть интересно** — рекомендации на основе истории предыдущих запросов (только для авторизованных пользователей)

### Авторизация и профиль
- Регистрация и вход через сайдбар (кнопка в правом верхнем углу)
- Токен-аутентификация (хранится в `localStorage`)
- Профиль показывает имя пользователя, счётчик запросов и историю поиска
- История поиска хранится в БД — каждый пользователь видит только свою
- Клик по запросу в истории подставляет его в строку поиска
- Возможность удалить отдельный запрос или очистить всю историю

## Установка и запуск

### Backend

```bash
cd backend
pip install -r requirements.txt
pip install sentence-transformers
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm install @ionic/react
npm start
```

Приложение доступно по адресу `http://localhost:3000`, бэкенд на `http://127.0.0.1:8000`.

## Загрузка датасета

Нажать кнопку **«Загрузить датасет»** и выбрать CSV-файл с колонками `title` и `text`.

При загрузке автоматически запускается:
1. Предобработка текста (лемматизация, удаление стоп-слов)
2. Обучение TF-IDF векторизатора
3. Построение SBERT-эмбеддингов для всего датасета

Ожидаемый формат CSV:
```
title,text
Заголовок статьи,Текст статьи...
```

## Структура проекта

```
RecommendationApp/
├── backend/
│   ├── config/             # Настройки Django
│   ├── ml_engine/
│   │   ├── preprocessor.py         # Предобработка русского текста
│   │   ├── vectorizer.py           # TF-IDF векторизация
│   │   ├── recomendation.py        # Рекомендации через TF-IDF
│   │   ├── embedding_recommender.py # Рекомендации через SBERT
│   │   └── process_pipeline.py     # Полный пайплайн обработки данных
│   ├── recs_api/
│   │   ├── models.py       # SearchHistory, AuthToken
│   │   └── views.py        # API эндпоинты
│   └── db.sqlite3
└── frontend/
    └── src/
        ├── App.js           # Главный компонент
        ├── ResultCard.js    # Карточка результата
        └── ProfileSidebar.js # Сайдбар профиля
```

## API эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/upload/` | Загрузка датасета |
| POST | `/api/search/` | Поиск рекомендаций (`query`, `method`) |
| POST | `/api/similar/` | Похожие статьи по ID |
| POST | `/api/history-recs/` | Рекомендации по истории |
| POST | `/api/auth/register/` | Регистрация |
| POST | `/api/auth/login/` | Вход |
| POST | `/api/auth/logout/` | Выход |
| GET  | `/api/auth/me/` | Текущий пользователь |
| GET  | `/api/auth/history/` | История поиска |
| POST | `/api/auth/history/clear/` | Очистить историю |
| POST | `/api/auth/history/delete/` | Удалить один запрос |
